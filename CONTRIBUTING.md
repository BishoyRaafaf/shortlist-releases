# Contributing

Thanks for wanting to help. Shortlist's source code is private, so this repository holds the releases, the README and the privacy policy. There are still plenty of ways to help.

## Report a bug

Use the **Feedback** page in the app (Ctrl+Shift+F). You can attach the log and a screenshot, and personal details are removed from the log before it's sent. If you prefer GitHub, [open a bug report](https://github.com/BishoyRaafaf/shortlist-releases/issues/new?template=bug_report.yml). That page is public, so leave your CV and personal details out.

## Suggest an idea

[Open a feature request](https://github.com/BishoyRaafaf/shortlist-releases/issues/new?template=feature_request.yml) or start a thread in [Discussions](https://github.com/BishoyRaafaf/shortlist-releases/discussions). Say what you were trying to do, not only the feature you want. It helps me find the simplest fix.

## Report scams and ghost jobs

This is the most useful thing you can do. In the app, open a job and choose **Report scam** or **Report ghost job**. Once several users on different networks report the same employer, everyone gets the warning.

## An employer flagged by mistake

[Open a "Wrongly flagged" request](https://github.com/BishoyRaafaf/shortlist-releases/issues/new?template=wrongly_flagged.yml) with the company name and website. I review every request.

## Spread the word

Tell a friend who is job hunting, or share the [download link](https://github.com/BishoyRaafaf/shortlist-releases). If Shortlist saved you time, a [donation](https://bishoyraafaf.github.io/shortlist-releases/support/) keeps it free.

## Pull requests

Fixes to the README or privacy policy (typos, broken links, clearer wording) are welcome. Code changes can't be accepted here because the code isn't in this repository.

# Security policy

## Supported versions

Only the latest release of Shortlist gets security fixes. The app updates itself, and older versions are asked to update before they keep working.

## Reporting a problem

Please don't open a public issue for a security problem.

- **Preferred:** use [Report a vulnerability](https://github.com/BishoyRaafaf/shortlist-releases/security/advisories/new). Only I can see it.
- **Or:** send it from the app's **Feedback** page (Ctrl+Shift+F). It goes straight to my inbox, not to a public page.

Tell me what you found, how to reproduce it, and which version you used (Settings → Data & about). I'll reply within 3 days and keep you posted until it's fixed. If you'd like credit in the release notes, say so.

## What's in scope

- The Shortlist app and its installer
- The community server the app talks to (scam and ghost-job reports, feedback, updates)
- Anything that could expose a user's CV, API key or other data stored on their PC

Please test only against your own installs and data. Don't flood the community server or send fake reports to test it.
